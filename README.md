# Kali-Linux-basic-system-information-and-network-testing.
Exploring information about Kali Linux machine's operating systems and hardware using commands such as whoami, hostname, uname -a, free -h, df –h, uptime, e.t.c.
Creating and changing directories and files, and their contents.Basic network connectivity test- pinging the public DNS of Google- 8.8.8.8 at 2 packets counts and pinging Google.com at 4 packet counts to determine that different servers, DNS lookup time and packet counts are potential reasons why their average round trip time of each ping differs.
